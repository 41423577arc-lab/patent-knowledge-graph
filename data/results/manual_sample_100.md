# P1-8 人工抽样核对（100 条）

生成时间：2026-11-25；标注完成：2026-11-26
文件：`manual_sample_100.csv`；随机种子 `20261125`。
指标文件：`data/results/manual_sample_100_metrics.json`。

## 1. 抽样

- 从 106,393 件专利中分层抽 100 件：专利类型 → 主主题领域 → 申请年段。
- 覆盖外观设计、无 IPC、无主题、无功效、有引用、多申请人等边界情况。
- 每行给出表内预测值（`applicant_std`、`ipc_main`、`topics`、`efficacy_l1`、`cites_count`、`coop_partners`）。

## 2. 核对方法

逐条对照标题、摘要、原始申请人、IPC、技术功效和引用字段，在 `label_*` 列填写：

- `1`：正确；
- `0.5`：部分正确；
- `0`：错误。

`notes` 记录非满分条目的原因。字段级准确率按 `(1×正确 + 0.5×部分) / 已核对条数` 计算。

字段对应：

| 列 | 核对对象 |
|---|---|
| `label_applicant` | 申请人拆分、去后缀、去重是否正确；对照 `applicant_raw` 与 `applicant_std` |
| `label_ipc` | 主 IPC 是否与原文一致 |
| `label_topic` | 主题是否过匹配/漏匹配；`（未细分）` 是否合理 |
| `label_efficacy` | 功效抽取是否对应原文 |
| `label_citation` | 引用方向/数量是否与原文一致 |
| `label_cooperation` | 本专利的共同申请人是否被 `coop_partners` 覆盖；单申请人无共同申请对 |

## 3. 核对结果

| 字段 | 核对条数 | 正确 | 部分正确 | 错误 | 准确率 |
|---|---:|---:|---:|---:|---:|
| 申请人 | 100 | 100 | 0 | 0 | **100%** |
| IPC | 100 | 100 | 0 | 0 | **100%** |
| 技术功效 | 100 | 100 | 0 | 0 | **100%** |
| 引用 | 100 | 100 | 0 | 0 | **100%** |
| 技术主题 | 100 | 50 | 35 | 15 | **67.5%** |
| 合作 | 9（多申请人） | 9 | 0 | 0 | **100%** |

补充说明：

- **引用边按边核对**：100 条专利共 418 条预测引用边、418 条原文引用边，命中 418 条；Precision = Recall = F1 = **1.00**。
- **合作字段分母为 9**：100 条中只有 9 条多申请人专利存在共同申请对；其余 91 条为单申请人，无共同申请对，不进入合作准确率分母。`coop_partners` 是申请人网络伙伴集合，用于检查本专利共同申请人是否被覆盖，不是单专利的共同申请人集合。
- **技术主题准确率**：100 条为 67.5%；剔除 18 条外观设计（无主题，按正确计）后，82 条非外观设计为 **60.4%**，其中完全正确 32 条、部分正确 35 条、错误 15 条。
- **结构化字段 100% 的边界**：申请人、IPC、功效、引用、合作都是由同一清洗/抽取链路直接生成，100 条抽样没有发现结构化错误；这不等于全量无错，也不能外推为“主题抽取也准确”。

## 4. 主题错误类型

15 条错误、35 条部分正确，主要集中在四类：

1. **兜底过粗**：只命中 `（未细分）`，没有细粒度主题。例如 S010、S021、S022、S024、S025、S033、S037、S044、S053、S055、S056、S097、S098。
2. **宽泛词误命中**：`回收`、`电池`、`芯片`、`换电`、`热失控` 等关键词过匹配。例如 S013、S015、S017、S019、S026、S043、S087、S091。
3. **空主题漏检**：应有主题但规则没有命中。例如 S041、S042、S079、S080、S082。
4. **部分正确**：命中一个主主题，但同时有误命中或漏掉一个明显主题。例如 S019、S020、S032、S034、S045、S048、S087、S092、S095、S096。

改进方向：补充“燃料电池”“整车结构”“充电控制”等词典；为 `回收`、`芯片`、`换电` 增加负向规则或上下文约束；`（未细分）` 继续单列，不混入细粒度主题排名。

## 5. 边界

- 100 条是分层抽样，用于估计字段级准确率，不是全量审计；全量结构一致性见 `contract_check.json`（34/34）。
- 标注按单条专利判断，不按全量统计口径加权；外观设计没有 IPC/主题/功效，相关字段按“应为空”判断。
- 主题判断依赖标题、摘要和功效文本；摘要翻译质量差的条目（如部分韩国、日本专利）可能存在判断误差。
- `notes` 中记录的是非满分条目的主要原因；满分条目没有逐条写“正确”，避免重复。
