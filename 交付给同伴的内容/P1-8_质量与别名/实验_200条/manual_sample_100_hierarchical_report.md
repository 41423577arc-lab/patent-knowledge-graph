# 100 条样本：放宽匹配标准实验

> 目的：只放宽“什么算匹配”，不改样本、不改主题词典、不改 P/R/F1 公式，观察指标能提高多少。
> 结论：把父子主题按 0.5 或 1.0 计入，主题级 F1 从 61.40% 只提高到 64.19% / 66.98%；领域级 67.39%。  
> 说明当前低分**不完全是精确匹配太严**，大部分差距仍是真实漏检/误判。

## 1. 三种匹配标准

同一个 100 条样本、同一个 50 个主题体系、同一个 micro P/R/F1 公式，只改“预测主题和参考主题怎样算匹配”：

| 口径 | 规则 |
|---|---|
| 严格（原口径） | 只有主题名完全相同才算 TP |
| 父子半分 | 预测/参考是父子关系（如 `热管理（未细分）` 与 `整车热管理`）算 0.5 TP |
| 父子全分 | 父子关系直接算 1 TP |
| 领域级 | 折叠到 8 个领域后比较，作为参照 |

父子关系按 `（未细分）` 兜底主题到细粒度主题的映射：

```text
热管理（未细分） → 电池热管理 / 整车热管理 / 电机电控热管理
充电（未细分）   → 充电桩 / 充电控制 / 快速充电 / 无线充电 / 换电 / 车网互动
电池（未细分）   → 电池热管理 / 电池成组与结构 / 电池管理系统 / 电池安全 / ...
电机（未细分）   → 驱动电机
电机控制（未细分）→ 电机控制
整车电控（未细分）→ 整车控制 / 电控与功率器件 / 电机控制
整车控制（未细分）→ 整车控制
整车动力（未细分）→ 驱动电机 / 减速器与传动
智能控制（未细分）→ 智能驾驶 / 环境感知 / 智能座舱 / 车规芯片
测试（未细分）   → 测试与验证 / 电池检测与诊断 / 电磁兼容
```

## 2. 结果

| 口径 | TP | FP | FN | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 严格（原口径） | 66.0 | 42.0 | 41.0 | 61.11% | 61.68% | **61.40%** |
| 父子半分 | 69.0 | 39.0 | 38.0 | 63.89% | 64.49% | **64.19%** |
| 父子全分 | 72.0 | 36.0 | 35.0 | 66.67% | 67.29% | **66.98%** |
| 领域级参照 | 62 | 31 | 29 | 66.67% | 68.13% | **67.39%** |

## 3. 怎么解读

- 严格 → 父子半分：F1 只提高 **2.79 个百分点**；
- 严格 → 父子全分：F1 只提高 **5.58 个百分点**；
- 父子全分已经接近领域级 67.39%，但仍不到 70%。

也就是说：

1. **精确匹配确实偏严**，把“粗/细粒度不一致”算成了 FP+FN；
2. 但放宽到父子关系后，只多认了 6 个主题边（TP 66→72），说明“粒度问题”不是全部；
3. 剩下的大部分缺口仍然是：细粒度主题漏检、宽泛词误命中、空预测、跨领域误判；
4. 领域级 67.39% 已经是比较宽的参照，仍未达到“很高”，说明规则本身还有真实错误。

## 4. 建议

- **原口径不改**：61.40% 继续作为严格指标；
- **新增一个父子半分口径**：64.19%，用于说明“粒度不匹配”的影响；
- **领域级 67.39%** 作为粗粒度指标；
- 三个数一起报，不互相替代；
- 不要把父子全分 66.98% 当成主指标，因为它把 `（未细分）` 直接算对了，会掩盖细粒度抽取能力不足。
