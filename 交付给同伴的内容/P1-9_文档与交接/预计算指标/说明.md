# 预计算指标（P1 → P2/P3）

生成：2026-11-26

这是 `company_metrics.parquet`、`topic_year.parquet`、`metrics_manifest.json` 的交付副本。仓库里的正式位置：

```text
data/_sample/results/     # USE_SAMPLE=true
data/results/             # USE_SAMPLE=false，全量
```

## 文件

| 目录 | 文件 | 内容 |
|---|---|---|
| `sample/` | `company_metrics.parquet` | 481 件样例，366 家主体 |
| `sample/` | `topic_year.parquet` | 295 行主题×年度 |
| `sample/` | `metrics_manifest.json` | `scope=sample`，含行数/SHA-256/源表行数 |
| `full/` | `company_metrics.parquet` | 106,393 件全量，27,557 家主体 |
| `full/` | `topic_year.parquet` | 1,293 行主题×年度 |
| `full/` | `metrics_manifest.json` | `scope=full` |

`company_metrics` 列：

```text
applicant_std, patent_count, cited_count, pagerank, degree, betweenness
```

`topic_year` 列：

```text
topic, domain, year, count
```

## 怎么用

把文件放回对应目录后：

```python
from core.data_loader import load_result
metrics = load_result("company_metrics")
yearly = load_result("topic_year")
```

`load_result` 会校验：

- 当前 `USE_SAMPLE` 对应的 scope 是 `sample` / `full`；
- 行数与 manifest 一致；
- 文件 SHA-256 与 manifest 一致；
- 列名与 `RESULT_COLUMNS` 一致。

样例/全量不会静默混用。缺文件或 manifest 不匹配会直接报错。

## 口径

- `company_metrics` 的引用网络只使用**样本内 CITES**，没有外部占位节点；`cited_count` 是样本内被引计数，不是全产业被引量。
- 样例 betweenness 精确计算（366 节点）；全量是采样近似（`k=128`, `seed=42`）。
- `topic_year` 只保留合法整数申请年和非空主题/领域；2024—2025 仍在表里，但页面趋势按 2010/2015—2023。
- P2 页面二请直接读 `company_metrics` 的 `patent_count/cited_count/pagerank/degree/betweenness`，不要在前端重算。

## 重算
